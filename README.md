# Online Examination & Evaluation System

An online exam platform where admins create exams, faculty manage question banks, and students attempt exams with time limits. The system auto-evaluates objective answers and generates result analytics.

## Key Focus Areas
- Exam scheduling & timers
- Question bank management
- Auto-evaluation logic
- Result analytics

## Tech Stack
- Flutter
- Real-time Analytics
